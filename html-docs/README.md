##  Welcome

HTML is **not** hard. It is just text with angle brackets around it. By the end of this guide you will have read every important concept, written real code, and built your own personal page — the first thing recruiters and developers Google when they hear your name.

This guide follows the **official MDN Core Learning Path** for HTML, expanded with extra explanations, real examples, exercises, and a Microdata bonus module that most beginner guides skip entirely.

**You do not need to know anything before starting.** You only need:
- A text editor (VS Code is recommended — it is free)
- A browser (Chrome, Firefox, or Edge all work fine)
- About 2–4 hours total across all modules

## How to Use This Repository

1. Start at Module 01 and work forward — they build on each other.
2. Type every code example yourself. Do not just read it.
3. Do the exercises. The answers are hidden — no peeking until you try.
4. After Module 11, start the final project alongside the remaining modules.
5. Push your résumé to GitHub Pages when done.

> **Pro tip:** If you get stuck on an exercise for more than 10 minutes, open the answer, understand it, close it, and then write it from memory. That is how it sticks.
