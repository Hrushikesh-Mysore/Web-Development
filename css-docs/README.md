## 👋 Welcome

HTML gives your page structure. CSS gives it a personality.

Without CSS, the web would be a sea of black Times New Roman on white backgrounds — technically usable, spiritually depressing. CSS is what makes a webpage feel like *something*. Colours, spacing, fonts, layout, animations — all of it is CSS.

This guide takes you from the very first line of CSS you have ever written all the way through Flexbox, Grid, and responsive design. By the end you will have styled your HTML résumé into something you are genuinely proud to share.

This guide follows both official MDN Core CSS learning paths:
- **CSS Styling Basics** — syntax, selectors, box model, cascade, colours, backgrounds
- **CSS Layout** — Flexbox, Grid, positioning, responsive design, media queries

**Prerequisite:** You should have finished (or be familiar with) the [HTML documentation](https://github.com/your-username/html-docs). CSS needs HTML to style — the two go hand in hand.

## 🚀 How to Use This Repo

1. Work through modules in order — each builds on the previous
2. Have a browser and VS Code open alongside — type the examples yourself
3. Do the exercises before peeking at the answers
4. Start the project once you reach Module 13 — style as you learn layout
5. Push your finished résumé to GitHub Pages

> **Pro tip:** Use the browser's DevTools throughout. Every concept in this guide can be experimented with live in DevTools without touching your files. It is the fastest feedback loop you have.
